## 怎么打开门牌

最简单：直接打开 `index.html`。

或者本地起个服务看看：

```bash
# 任选其一
npx serve .
python3 -m http.server 8000
node -e "require('http').createServer((q,s)=>s.end(require('fs').readFileSync('index.html','utf8'))).listen(8000)"
```

然后浏览器访问 <http://127.0.0.1:8000>
